# Café Chez Jad – Menu numérique (site statique)
HTML + CSS + JavaScript pur. Aucun build, aucune dépendance.

## Ouvrir en local
Double-cliquez sur `index.html`.

## Menu / prix
Modifiez le tableau `MENU` en haut de `script.js`.

## Netlify
1. app.netlify.com → Add new site → Deploy manually, puis glissez-déposez le dossier du projet
   (ou importez le dépôt GitHub).
2. Build command : laisser vide. Publish directory : laisser vide (la racine du projet).
3. Netlify fournit une URL stable (modifiable dans Site settings → Domain management).

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.

## QR code
Générez un QR « URL statique » (SVG/PNG haute résolution) vers l'URL finale déployée, testez-le avec un téléphone, puis imprimez-le.
